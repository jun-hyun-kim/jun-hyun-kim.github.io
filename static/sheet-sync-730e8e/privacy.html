Privacy Policy

Last updated: October 8, 2026

Job Research Sheet Sync is a personal tool used only by its owner.

Data accessed

With your permission, the app uses the Google Sheets API (spreadsheets scope) to read and write the spreadsheet it is configured to manage. It does not access any other Google data.

How data is used and stored

Spreadsheet data is used only to update that spreadsheet. The OAuth token is stored only on the owner's computer. No data is sold, shared with third parties, or used for advertising.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke access at any time at myaccount.google.com/permissions.
